# 0.1.17 更新诊断包使用说明

此安装包只用于排查 Windows “检查更新”偶发失败。它保持正式版 `0.1.17` 的应用身份、便签数据目录和正式更新源，只增加本地 updater 日志，不会自动上传任何数据。

## 安装前

1. 从托盘退出悬浮便签。
2. 建议备份 `%APPDATA%\floating-sticky-notes`（诊断包不会主动删除或迁移这里的数据）。
3. 运行 `StickyNotes-Setup-0.1.17-Update-Diagnostic.exe`，覆盖安装到原位置。

## 复现步骤

1. 启动后先不要点击“检查更新”，等待 90 秒，让启动自动检查完成或暴露卡住状态。
2. 右键托盘图标，点击“打开更新诊断日志”。保留此时的 `updater-diagnostic.log`。
3. 回到托盘，只点击一次“检查更新”，等待明确的“已经是最新版本”或“检查更新失败”。不要连续点击。
4. 再点击“打开更新诊断日志”，把 `updater-diagnostic.log` 发回。如果同目录存在 `.1` / `.2` 备份，也一并发回。
5. 如果方便，切换手机热点后退出并重新启动应用，再重复以上步骤。

> [!warning]
> 如果启动后 90 秒仍没有自动更新结果，不要先退出应用。直接点击“打开更新诊断日志”，复制当前日志后，再继续手动检查；这样能保留卡住期间的现场。

## 日志位置

`%APPDATA%\floating-sticky-notes\logs\updater-diagnostic.log`

日志记录应用/Windows 版本、自动或手动检查来源、更新状态、GitHub 请求 URL（不含 query）、耗时、HTTP 状态和错误码；不记录便签、待办、图片内容、用户名、机器名、IP、Cookie 或 Token。

## 结束后

可重新安装官方 `0.1.17` Setup 恢复正式包。诊断日志不会被安装器自动删除，如不再需要可手动删除 `logs` 目录。
