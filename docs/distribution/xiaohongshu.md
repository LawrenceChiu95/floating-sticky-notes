记了那么多待办，后来你看过几次？

备选：

- 便利贴，就该贴在眼前

## 正文

有些事，认真记下了，却没再看过。

写进待办，最小化窗口，再打开几个页面。
刚才记下的事，就这样退出了视线。

做这个便签时，我想到的是现实里的便利贴和书签。
一张贴在眼前，一小截露在书页外。
每次看见，都是一次重新想起的机会。

所以「悬浮便签」会一直留在普通工作窗口上方。
写文档、查网页，要记的事还在眼前。
待办可以边做边勾，刚冒出来的灵感、需要参考的截图，也能贴进去。

要给工作腾点地方，就收成横条，再贴到屏幕边上。
留在眼前，也懂得让开。

这是「看见」的力量。

不用注册账号，文字和图片都保存在自己的电脑里。
Windows 和 Apple Silicon Mac 都能用，当前版本免费下载，MIT 开源。

项目叫「悬浮便签」，GitHub 搜索：
LawrenceChiu95 / floating-sticky-notes

如果喜欢，也欢迎在 GitHub 点个 Star，支持我继续把它打磨好。

## 安装问题回复备用

Mac 当前只提供 Apple Silicon 版本。下载后拖入 Applications；由于尚未使用 Apple Developer ID 和公证，首次打开可能要去「系统设置 → 隐私与安全性」点「仍要打开」。Windows 提供 x64 Setup，安装包暂未签名。

下载入口：<https://github.com/LawrenceChiu95/floating-sticky-notes-updates/releases/latest>。
