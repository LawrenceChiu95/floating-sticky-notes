# Issue #15 “更多”菜单纸面一致性 — 证据与验证(2026-07-25)

> 17 张脱敏对比 PNG 已随本记录保存在 `debug-log/issue-15-menu-visual-20260725/`，仅包含名为“诊断15”的测试便签与应用界面，用于复核颜色、透明度、窄窗裁切和交互状态。

## 改动前证据(真实 Electron 窗口,CDP 实采)

- 菜单背景固定 `rgba(252, 250, 244, 0.98)`,与便签颜色无关;黄/绿/蓝/粉四色便签上菜单读作外来系统面板,白色便签上恰好接近。
- 纸面语言为内投影(`inset 0 1px 0 rgba(255,255,255,0.24)` + `inset 0 -1px 0 rgba(43,42,39,0.06)`),菜单当时只有外投影,无纸面边缘。
- 边框/圆角/hover 本就与纸面同 token(`rgba(43,42,39,0.12)`、`8px`、`rgba(43,42,39,0.08)`),不是失配点。
- 200px 窗口下菜单 `x=11,w=160`,未裁切;问题纯粹是颜色与边缘语言。

## 方案(最小改动)

- 新增 `noteColorToMenuSurface(color)`:便签纸色向白抬升 55%,alpha 固定 0.97,作为 CSS 变量 `--note-menu-surface` 挂在 `.note-shell` 内联样式。
- `.more-menu` 与 `.note-delete-confirm` 共用该变量(回落值为原 `rgba(252,250,244,0.98)`),并叠加纸面同款内高光/内暗边 + 原浮层投影。
- 不改动作层级、按钮尺寸、命名/收起布局、菜单位置与行高;hover/focus 沿用纸面 overlay,已验证可读。
- 典型计算值:黄 `rgba(255,250,219,0.97)`、绿 `rgba(240,251,234,0.97)`、蓝 `rgba(237,246,255,0.97)`、粉 `rgba(255,239,245,0.97)`、白 `rgba(253,253,251,0.97)`。

- 200px:菜单 `x=11,w=160`、删除确认 `x=7,w=179`,均未裁切。
- 真实 pointerdown/up:点“外观”→ 菜单关、外观面板开;外部点击 → 菜单关闭。
- 打开菜单焦点自动落在首个 menuitem;`Esc` 关闭并回焦“更多”按钮。
- 真实点击删除按钮 → 确认条为同色纸面;点“取消”便签保留。
- 低透明度(0.6)下菜单保持 0.97 不透明,内容可读。
